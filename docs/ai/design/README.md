# County qualification design

Private SECURITY INVOKER SQL worker -> official parcel polygon -> FEMA/NWI/roads
-> mapped ROW metrics -> qualification snapshot -> DD qualification hold ->
qualified contact-enrichment lead only after every prerequisite passes.

Use a fixed county-source registry, 8-second request limits, at most two attempts,
and POST for long polygon requests. PostGIS 3.3.7 builds rings into areas and
measures in EPSG:26917. The 0.20m line-matching tolerance is explicit.
No proximity measurement grants legal access. Recorded document approval
requires a document hash, instrument reference, reviewer, and expiry.
